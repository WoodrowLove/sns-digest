# SNS Digest

Weekly plain-English read on what's happening across Internet Computer SNS DAOs.

One human, Claude for reasoning, public API data, zero shilling. Issued every Tuesday.

## Issues

- [#1 — April 22, 2026](./issues/001-2026-04-22.md) — OpenChat open votes, KongSwap sunset drama, ORIGYN's five-rejection streak

## Why

Most SNS token holders don't vote. Proposals drop unpredictably; each takes 20+ minutes to parse; delegation is all-or-nothing. This digest exists to make participation cheaper — skim a page instead of chasing five forums.

## What this becomes

Progressive automation. Week 1 is me plus Claude writing summaries. By week 4, proposal fetching and summarization are automated. By week 8, it's a canister-native agent ([Kairos](https://forum.dfinity.org/t/validation-kairos-managed-autonomous-governance-agents-for-sns-built-on-anda-rfp-9/67763)) that you configure with a policy and it votes on your behalf — or escalates to you when confidence is low. Built on the [Anda Framework](https://github.com/ldclabs/anda).
