Hey all,

Started something small this week. Every Tuesday I'm publishing a plain-English read on what's happening across ICP SNS DAOs — who's voting on what, where the interesting tensions are, and what's worth clicking into. One page, skim-able in 5 minutes.

Issue #1 is live:

**https://github.com/WoodrowLove/sns-digest/blob/main/issues/001-2026-04-22.md**

(GitHub Pages is building — a cleaner URL at woodrowlove.github.io/sns-digest/ comes online shortly.)

**What's in this week:**

- **OpenChat #2266** is a genuine coin-flip (38.6% YES) on whether to approve the HashEra Known Neuron registration. Worth a look if you hold CHAT.
- **KongSwap** rejected the Doxa Foundation takeover (2.6% YES). Team is sunsetting; LPs told to withdraw by April 6.
- **ORIGYN** rejected five token-economic proposals in a row, all at ~4% YES. Uniform tallies suggest concentrated NO vote across very different proposal types.
- **ELNA AI** rejected a paid-shilling proposal at 62.8% YES (needed supermajority). Interesting cultural signal.

**Why I'm doing this:**

I'm scoping [Kairos](https://forum.dfinity.org/t/validation-kairos-managed-autonomous-governance-agents-for-sns-built-on-anda-rfp-9/67763) — managed autonomous governance agents on ICP, built on Anda — and before I write a line of production code I wanted to actually do the work of reading proposals myself. The digest doubles as:
1. A useful free thing for SNS participants (please tell me what's missing or wrong)
2. A living spec for what an agent should automate
3. A public track record so when I apply for RFP-9 later, there's evidence I can ship

The progression: issue #1 is me + Claude writing manually. By issue #4 the fetch + preliminary summary is automated. By issue #8 it's an agent canister running on Anda that you can configure with your own YAML policy.

**I want to know:**

3. For anyone who votes regularly — what's the single most time-consuming step in your current workflow? That's where the agent adds the most value.

Pull requests / issues / replies welcome. This is v0.1, I'll almost certainly get things wrong.
